# ADR 0001: Preparation before event-specific implementation

Status: accepted in the user's implementation request, 2026-09-05.

The accepted plan explicitly limits work before event-specific clarification to
research, documentation, learning, and general environment preparation. The
[general lablab guide](https://lablab.ai/guide/ai-hackathons) says most events reserve
core AI functionality for their build window, but this is not an event-specific ruling.

Implement general runtime checks, a generic pendulum learning example, file
integrity records, a documentation/learning portal, and engineering specifications.
Do not implement the dinner scene, teacher, learned policies, or manipulation
supervisor until the clarification is recorded. This avoids silently changing an
explicit constraint of the user's plan.

No additional user approval is needed for the independent preparation work. A
future explicit user direction changing the scope must be considered alongside
the event's actual eligibility requirements and recorded transparently.

Consequence: preparation can be delivered now; the full application remains
unfinished, and no manipulation or Intel success is claimed.
