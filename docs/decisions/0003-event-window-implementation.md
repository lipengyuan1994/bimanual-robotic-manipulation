# ADR 0003: Begin simulation implementation in the event window

Status: accepted, September 10, 2026. Supersedes ADR 0001's forward-looking
preparation-only restriction, while preserving that decision as historical context.

The signed-in [event page](https://lablab.ai/ai-hackathons/ai-infra-summit-hackathon)
instructs online teams to join the September 10 kickoff and start building, with
no track assignment required. The user subsequently explicitly authorized the
proposed M1 work and research into free Intel access ("go ahead, work on this").
This decision relies on those instructions, not merely elapsed time.

Proceed with the accepted simulation-only architecture. First deliver dual SO-101
loading, deterministic joint mappings, bounded controls, overhead/wrist cameras,
and reproducible foundation evidence. Drawer/grasp/hand-off, learned policies,
and production reliability remain separate uncompleted gates in M1–M4.

Existing preparation-code eligibility has no explicit organizer ruling. Preserve
Git history and disclose pre-event runtime/documentation/learning work; do not
claim retroactive organizer approval. Intel hardware access, final hosting details,
and pouring scope remain open. Spend stays zero. No external message is authorized
by this decision and none has been sent.
