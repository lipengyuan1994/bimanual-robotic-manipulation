# Fixed-scene dinner teacher, version 1

The scene and frozen joint-target plan originate from sealed run
`20260911T011032-a9fda4aee41f`. The manifest binds the source seal, source actions,
IK driver and packaged files. The plan contains 4,819 joint targets at 20 Hz;
physics runs at 1 kHz. Joint angles are radians, left six followed by right six.
Camera and joint names are explicit in the plan.

These targets were generated by the scripted, bounded IK teacher. Executing them
requires fresh contact physics, collision checks and independent outcome scoring.
This is a single authored scene baseline, not an adaptive or learned controller.
The plan contains no object poses, force commands, attachments or scoring results.
Historical experiment directories are not needed at runtime.

SO-101 geometry, actuator parameters and joint limits derive from the adjacent
`robotstudio_so101` model. Its LICENSE and UPSTREAM.json remain authoritative;
the dinner command copies them and the original meshes into each evidence bundle.
Project-authored tableware, scene composition and target plan use the repository's
MIT license. Preserve both licenses when redistributing.
